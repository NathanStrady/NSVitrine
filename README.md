# Portfolio de Nathan Strady

Bienvenue sur le code source de mon portfolio. Vous pouvez voir la disposition du projet et le code dans les différents dossiers.

Le projet est réalisé sous Next.js, TypeScript, HeroUI et est déployé via Vercel.

## 🚀 À propos de moi
Hello, je m'appelle Nathan Strady et je suis le développeur de ce site portfolio !

Ayant grandi avec des jeux de stratégie comme StarCraft 2 et des JRPG comme les Tales of, je considère que les systèmes de jeu font la majorité du fun. C'est pour cela que je m'oriente vers leur implémentation en tant que Gameplay Programmer.

Ce portfolio a donc pour but de présenter les travaux que j'ai pu réaliser dans le domaine du jeu vidéo en tant que Gameplay Programmer !
